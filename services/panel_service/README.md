## Панель управления

Вспомогательный сервис для разработки. Показывает весь проект на одной схеме: какие сервисы и базы запущены, позволяет вызывать ручки и смотреть содержимое таблиц. Базы открываются только на чтение.

### Запуск

```bash
cd services/panel_service
uvicorn main:app --port 9000
```

Панель: [http://127.0.0.1:9000](http://127.0.0.1:9000)

### Что умеет

* Схема всех сервисов и баз из архитектурного плана. Выключенные узлы остаются на схеме и помечаются.
* Статусы по `/health` каждые 5 секунд.
* Список ручек сервиса: из `openapi.json`, если сервис запущен, иначе из плана.
* Отправка запросов в сервис напрямую или через gateway с токеном-заглушкой.
* Превью таблиц с поиском по всем колонкам.
* Поиск по сервисам, ручкам и таблицам (`/`).

Узлы можно перетаскивать, расположение сохраняется в браузере.

Шрифт SF Pro встроен в `static/fonts` (только латиница и кириллица), интернет для панели не нужен.

### Переменные окружения

| Переменная | По умолчанию |
|---|---|
| `GATEWAY_URL`, `USERS_SERVICE_URL` ... `STATS_SERVICE_URL` | `http://127.0.0.1:8000` ... `8005` |
| `USERS_DB_URL`, `CATALOG_DB_URL`, `REQUESTS_DB_URL`, `LOCKERS_DB_URL` | `sqlite:///services/<сервис>/<база>.db` |

Схема проекта описана в `topology.py`: при добавлении сервиса, ручки или таблицы достаточно дописать их туда.

### Паттерны

* **Singleton** - `PanelConfigSingleton`
* **Adapter** - `OpenApiAdapter`
* **Factory Method** - `DatabaseReaderFactory`
