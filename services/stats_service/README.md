# Stats Service

Микросервис сбора, расчёта аналитических показателей по гарантийным заявкам, эффективности сотрудников сервисного центра и обращениям по электротоварам с формированием JSON-ответов и экспортом в CSV для руководителя (начальника сервисного центра).

## Порт и запуск

- **Порт:** `8005`
- **База данных:** общая БД заявок `requests_db` (режим только для чтения: `REQUESTS_DB_URL`).

### Запуск сервиса локально:
```bash
uvicorn main:app --host 0.0.0.0 --port 8005 --reload
```

## Архитектура и реализованные паттерны GoF

1. **Singleton** - `StatsConfigSingleton` (`clients.py`):
   Централизованное управление адресами микросервисов (`USERS_SERVICE_URL`, `CATALOG_SERVICE_URL`), таймаутами и строкой подключения к БД.
2. **Adapter + Caching** - `ExternalServiceAdapter` (`clients.py`):
   Адаптирует межсервисные вызовы к `users-service` (получение ФИО сотрудника) и `catalog-service` (получение наименования и категории товара) со встроенным кэшированием в оперативной памяти для исключения повторных сетевых вызовов.
3. **Strategy** - `ReportFormatterStrategy` (`patterns.py`):
   Инкапсулирует алгоритмы форматирования аналитических данных:
   - `JsonReportFormatter` — структурированные JSON-данные для дашборда веб-кабинета руководителя.
   - `CsvReportFormatter` — генерация выгрузок в формате CSV с разделителем `;` и кодировкой `UTF-8 с BOM` в точном соответствии с утвержденными шаблонами Таблиц 3, 4, 5 Проектного решения (ПР) для MS Excel и Р-7 Офис.
4. **Facade** - `StatsServiceFacade` (`patterns.py`):
   Координирует извлечение заявок из общей БД, применение фильтров по датам, расчёт агрегированных показателей (среднее время обслуживания, распределение по статусам, ранжирование товаров) и делегирование выбранной стратегии форматирования.

## Точки входа (API Endpoints)

- `GET /health` - проверка доступности сервиса и чтения из `requests_db`.
- `GET /api/v1/stats/requests` - отчёт о заявках за период (`from`, `to`, `format=json|csv`).
  - Шаблон CSV: `№ заявки;Дата создания;Товар;Сотрудник;Статус;Дата закрытия` (Таблица 3 ПР).
- `GET /api/v1/stats/employees` - показатели эффективности сотрудников (`from`, `to`, `format=json|csv`).
  - Шаблон CSV: `ФИО сотрудника;Обработано заявок;Среднее время обработки, дн.` (Таблица 4 ПР).
- `GET /api/v1/stats/products` - рейтинг электротоваров по количеству гарантийных обращений (`from`, `to`, `format=json|csv`).
  - Шаблон CSV: `Товар;Категория;Количество заявок` (Таблица 5 ПР).
